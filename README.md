# arch-linux-raid1
Установка Arch Linux на программный RAID1 в QEMU. Настройка BIOS/UEFI и проверка отказоустойчивости

## Выполнение работы
1. Созданы два виртуальных диска QEMU по 20 ГиБ.
2. Выполнена разметка дисков и создан программный RAID1 с помощью mdadm.
3. Установлен Arch Linux и настроены необходимые системные файлы.
4. Настроен загрузчик GRUB для работы в режимах BIOS и UEFI.
5. Проверена загрузка системы при отключении каждого из двух дисков по отдельности.
6. Проверена автоматическая сборка неполного RAID1 при загрузке.
7. Восстановлена работа RAID1 с двумя дисками.
8. Выполнена проверка согласованности данных массива.

Скриншот выполнения работы находятся в папке screenshots.
